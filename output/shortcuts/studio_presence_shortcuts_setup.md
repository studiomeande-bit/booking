# Studio Presence iPhone Shortcuts Setup

독일 스튜디오 운영 기준으로 가장 안정적인 방식은, 아이폰 단축어가 직접 캘린더에 `Studio Open` 이벤트를 생성/삭제하도록 만드는 것입니다.

현재 예약 시스템은 아래 조건의 이벤트를 읽어서 추가 예약 슬롯을 자동으로 엽니다.

- 제목: `Studio Open`
- 위치: `Holzweg-passage 3, 61440 Oberursel`
- 캘린더: `사진촬영 일정`
- 대상 예약: `여권 / 프로필 / 스튜디오`

## 1. 도착용 단축어 만들기

단축어 이름:

- `Studio Open`

권장 액션 순서:

1. `현재 날짜 가져오기`
2. `날짜 조정`
   - 현재 날짜에 `2시간` 더하기
3. `새로운 이벤트 추가`
   - 제목: `Studio Open`
   - 시작: `현재 날짜`
   - 종료: `조정된 날짜`
   - 위치: `Holzweg-passage 3, 61440 Oberursel`
   - 캘린더: `사진촬영 일정`
   - 메모: `Studio presence auto-open`

권장값:

- 기본 오픈 시간: `2시간`
- 더 길게 상주할 때는 `4시간` 또는 `종료 시 수동 닫기`

## 2. 출발용 단축어 만들기

단축어 이름:

- `Studio Close`

권장 액션 순서:

1. `이벤트 찾기`
   - 캘린더: `사진촬영 일정`
   - 제목 포함: `Studio Open`
   - 시작일: `오늘`
2. `이벤트 삭제`

## 3. 위치 자동화 만들기

### 도착 자동화

1. 단축어 앱 → `자동화`
2. `개인용 자동화 생성`
3. `도착할 때`
4. 위치: `Holzweg-passage 3, 61440 Oberursel`
5. 실행 단축어: `Studio Open`

### 출발 자동화

1. 단축어 앱 → `자동화`
2. `개인용 자동화 생성`
3. `떠날 때`
4. 위치: `Holzweg-passage 3, 61440 Oberursel`
5. 실행 단축어: `Studio Close`

## 4. 운영 메모

- `Studio Open` 이벤트가 있으면 기존 영업시간 밖이어도 예약 슬롯이 열립니다.
- 실제 예약/개인 일정과 충돌하는 시간은 계속 막힙니다.
- `야외 / 웨딩 / 기업행사`는 추가 오픈 대상이 아닙니다.
- 픽업 일정은 같은 시간이어도 허용됩니다.
- 예약 화면 반영은 최대 `약 2분` 정도 걸릴 수 있습니다.

## 5. 추천 운영 방식

- 잠깐 들를 때: `2시간`
- 하루 절반 상주: `4시간`
- 길게 있을 때: 도착 시 `4시간` 열고, 퇴근 시 `Studio Close`로 닫기
