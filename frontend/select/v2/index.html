셀렉 진행 순서 안내
  1. 1차 셀렉 (별점 분류) — 드라이브에 업로드된 모든 사진을 둘러보며 별 1개~5개로 분류해 주세요. 마우스를 올리면 큰 화면으로 미리볼 수 있고, 키보드 숫자키(1~5)로 빠르게 별점을 줄 수 있습니다.
  2. 보정 사진 선택 — 별점을 준 사진들이 보정 목록에 자동으로 채워집니다. 기본 포함 장수까지는 무료, 기본 장수 이후(예: 11번째부터)는 추가 보정 비용이 자동 계산됩니다. 사진별로 원하는 보정 요청사항과 인화 사이즈를 적어주세요.
  3. 추가 인화 — 보정 신청은 하지 않더라도 추가로 인화만 받고 싶은 사진이 있다면 여기에서 입력해 주세요.
  4. 최종 확인 & 수령 방식 — 지금까지 고른 내용을 마지막으로 확인하고, 스튜디오 픽업 또는 우편 수령을 선택한 후 제출하시면 끝입니다.
모든 단계는 언제든 이전으로 돌아가 수정할 수 있으니 편하게 진행하셔도 됩니다. 제출 이후에도 마감일 전까지는 수정이 가능합니다.
보정 요청 작성 방법
보다 정확한 보정을 위해, 요청은 가능한 한 구체적으로 작성해 주세요. 아래 예시를 참고하시면 좋습니다.
방향을 잡기 어려운 요청
  • “0001번: 자연스럽게 해주세요”
  • “0002번: 눈/입 수정해주세요”
정확도가 높아지는 요청
  • “0003번: 얼굴 라인을 자연스럽게 정리해 주세요.”
  • “0012번: 이마 번들거림을 줄이고 피부 톤을 조금 더 균일하게 해주세요.”
  • “0031번: 옷 주름(어깨/가슴)을 자연스럽게 정리해 주세요.”
또한 이름 · 날짜 · 짧은 문구 등의 레터링 및 텍스트 디자인은 무료로 제공됩니다.

1차 셀렉 — 별점으로 사진 분류

사진 위에 마우스를 올리면 큰 화면으로 미리보기가 나타납니다. 사진을 클릭하거나 키보드 숫자키(1~5)로 별점을 주세요. 0을 누르면 별점이 해제됩니다. 별점을 준 사진은 다음 단계에서 자동으로 보정 목록에 담깁니다.

마케팅 동의  + 보정 2장 무료 추가

선택해 주신 사진이 Studio mean의 포트폴리오·SNS 예시 이미지로 소개되어도 괜찮은지 편하게 선택해 주세요. 동의해 주시면 보너스 보정 2장이 무료로 추가됩니다. 원치 않으시면 미동의를 선택하시면 됩니다.

평점 기준 안내
  • 5점 꼭 보정받고 싶은 사진 (베스트 컷)
  • 4점 마음에 드는 사진 (보정 우선순위 높음)
  • 3점 괜찮은 사진 (추가 인화 후보)
  • 2점 다시 한번 고민할 사진
  • 1점 가볍게 표시만 해둔 사진

보정 사진 선택

1차 셀렉에서 별점을 준 사진은 모두 무료로 보정 목록에 담깁니다. 기본 포함 장수를 초과해도 갤러리에서 고른 사진은 추가 비용이 발생하지 않습니다. 사진별로 보정 요청사항을 가능한 구체적으로 적어주세요. (아래 버튼으로 직접 추가한 사진은 기본 포함 장수를 넘으면 추가 보정 비용이 발생합니다.)
