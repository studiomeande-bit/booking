# Gutschein V1 Plan

Updated: 2026-04-22 Europe/Berlin

## Goal

독일 사진/영상 스튜디오 운영에 맞는 `Gutschein` 1차 버전을 추가한다.

Status: V1 운영 기능과 세무 안전 장부 필드는 2026-05-08 배포 `@468` 기준 반영됨.

이번 1차 버전의 목표는 아래 3가지다.

- 오프라인에서 미리 출력해 둔 엽서형 굿샤인을 안전하게 재고 관리
- 어드민에서 즉시 발행 / 재고 등록 / 메일 발송 / 예약 적용 가능
- 예약장부와 굿샤인 장부가 동시에 업데이트되도록 하여 중복 사용을 방지

## Scope

1차 버전은 아래만 포함한다.

- 관리자 발행
- 재고형 굿샤인 배치 생성
- 즉시 발행형 굿샤인 생성
- 랜덤 코드 + QR 포함 PDF 생성
- 예약장부에서 QR 스캔 또는 코드 입력으로 적용
- 적용 시 사용 완료 처리
- 전체 금액에서 차감 후 잔금 계산
- 굿샤인 장부 / 예약장부 동시 기록

이번 버전에서 제외한다.

- 고객 예약 화면 직접 입력
- 부분 사용 / 잔액 이월
- 자동 환불 복원
- 온라인 결제 연동

## Voucher Types

두 가지 타입으로 시작한다.

- `amount`
  - 금액권
  - 예: `€50`, `€100`, `€150`, 직접입력
- `product`
  - 상품권
  - 발행 시점의 `productId`, `상품명`, `총액`을 스냅샷 저장

## Voucher Code

- 연속 번호 대신 랜덤 코드 사용
- 형식 예시: `8K4M-X7Q2-N9PW`
- 혼동되는 문자 제외
  - `0`, `O`, `1`, `I`, `l`
- 생성 후 DB 중복 검사
- 중복 시 재생성

기존 `generateSessionId_()`의 문자 세트를 참고해 같은 계열로 생성한다.

## QR Strategy

- QR에는 단순 코드보다 `검증 URL + code`를 넣는다.
- 예:
  - `https://booking.studio-mean.com/gutschein/check?code=8K4M-X7Q2-N9PW`
- 예약장부에서 QR 스캔 시 URL의 `code` 파라미터를 추출한다.
- 텍스트 코드도 PDF에 같이 인쇄한다.

## Reservation Apply Flow

적용은 예약장부에서만 가능하다.

흐름:

1. 관리자 QR 스캔 또는 코드 입력
2. 서버가 코드 조회
3. 아래 항목 검증
   - 상태가 `판매완료`인지
   - 사용여부가 `N`인지
   - 유효기한이 지났는지
4. 검증 성공 시 예약 총액에 차감 계산
5. `LockService`로 잠금 후 저장
6. 예약장부와 굿샤인 장부를 동시에 업데이트
7. 상태를 `사용완료`로 전환

## Amount Calculation

계산 규칙:

- `조정총액 = max(0, 원래총액 - 굿샤인차감액)`
- `최종잔금 = max(0, 조정총액 - 이미받은예약금)`

예시:

- 총액 `€650`
- 예약금 `€100`
- 굿샤인 `€150`
- 조정총액 `€500`
- 최종잔금 `€400`

1차 버전에서는 잔액 이월을 지원하지 않는다.

즉:

- 굿샤인 금액이 예약 총액보다 커도 전액 사용 처리
- 남은 잔액은 저장하지 않음
