# 인화·액자 단가 개정안 (2026-09-09 검토용)

> 상태: **사장님 검토 대기**. 승인 시 `PRINT_LABELS`(Code.gs) + 셀렉 화면 문구 반영.
> 현행 단가는 `PRINT_LABELS` 가 정본이며 이 문서는 그 개정 제안이다.

## 1. 왜 손대는가

- 사장님 질문: "전문 프린트 샵보다 비싼 거 아니야?" → **같은 용지 기준으로 확인한 결과 A3 이상은 실제로 비싸다.**
- 우리는 **하네뮐러 용지 + 염료(dye) 잉크**다. 전문 랩은 같은 용지에 **안료 잉크 + 프로파일링 장비**다.
  품질 우위를 주장할 수 없다 → **보존 연수·미술관급 같은 문구는 쓰지 않는다.**
- 대신 비교가 성립하지 않는 영역(액자 완성품)으로 상단을 옮긴다.

|---|---|---|
| 랩 하네뮐러 Baryta A4 | €15.15 (부가세 포함) | digiposter.de |
| 랩 하네뮐러 Baryta A3 | €28.90 | 〃 |
| 랩 하네뮐러 Baryta A2 | €56.90 | 〃 |
| 랩 배송 | 편지 €4.20~ / DHL €7.40~ / 픽업 €0 | 〃 |
| 하네뮐러 인증 파트너 | **용지당 최소주문 €20** + 배송 €7.90 | artidomo.de |
| 하네뮐러 Photo Rag A3+ 25장 | €129.95 → **장당 €5.20** | fine-art-papiere.de |
| IKEA RÖDALM 30×40 | €6.99 · 마운트 포함(창 21×30) | ikea.de |
| IKEA RÖDALM 40×50 | €9.99 · 마운트 포함(창 **29×39**) | ikea.de |
| IKEA FISKBO 21×30 / 30×40 | €1.99 / €2.99 · 마운트 없음 | ikea.de |

→ 고객이 랩에서 **A3 한 장**을 실제로 받는 값 = **€33~37**(최소주문·배송 포함).
→ 우리 A3 보정본 €35 는 대등, **원본 €50 은 확실히 위**.

**용지 규격 문제**: 파인아트 용지는 DIN(A3/A3+) 이 표준이라 IKEA cm 규격(30×40)용 용지는 조달이 어렵다.
→ **A3 를 뽑아 마운트로 가리는 방식이 맞다**(마운트는 원래 인화 가장자리를 덮는 물건).
   RÖDALM 40×50 창이 29×39 이므로 A3(29.7×42)는 좌우 0.35 · 상하 1.5cm 가 덮인다.
   **출력 시 상하 여백 1.5cm 프리셋**을 두면 사진 자체는 잘리지 않는다.
   A3+(32.9×48.3)는 맞는 액자가 없다 → **낱장 전용 유지**.

## 3. 재료 원가와 마진 (현행가 기준)

장당 재료비 = 용지(면적 환산) + 염료 잉크.

| | 판매가(원본/보정본) | 실수령 | 재료비 | 재료 마진 |
|---|---|---|---|---|
| 파인아트 A4 | 20 / 15 | 16.81 / 12.61 | €2.5 | 85% / 80% |
| 파인아트 A3 | 50 / 35 | 42.02 / 29.41 | €4.9 | 88% / 83% |
| 파인아트 A3+ | 60 / 45 | 50.42 / 37.82 | €6.2 | 88% / 84% |

재료 마진은 넉넉하다. **제약은 원가가 아니라 랩 시세와 핸들링 시간**이다.

## 4. 제안

### 4-1. 인화 단가

| 상품 | 현행 | 제안 | 근거 |
|---|---|---|---|
| 시그니처 10×15 · A4 | 4/3 · 15/10 | **유지** | 랩과 직접 비교되는 구간 |
| 파인아트 10×15 · A4 | 8/6 · 20/15 | **유지** | 랩 A4 €15.15+배송과 대등 |
| 파인아트 A3 | 50 / 35 | **42 / 34** | 랩 실수령 €33~37 방어선 |
| 파인아트 A3+ | 60 / 45 | **52 / 44** | 동일 논리 |
| 포토카드 단면/양면 | 5/5 · 8/8 | **6/5 · 9/7** | 원본·보정본 차등이 없던 예외 정리 |

### 4-2. 액자 (신설)

| SKU | 액자 | 원가 | 추가금 | 세트 예시 |
|---|---|---|---|---|
| `frame_a4` | RÖDALM 30×40 | €6.99 | **+€35** | 파인아트 A4 + 액자 = **€50** |
| `frame_a3` | RÖDALM 40×50 | €9.99 | **+€45** | 파인아트 A3 + 액자 = **€79** |

A3 세트 €79 → 실수령 €66, 원가(용지 4.1 + 잉크 0.8 + 액자 10 + 백보드·포장 3 + 조립 20분 ≈ €38) → **마진 €28(43%)**.

**계산 규칙**: 액자는 **포함 인화 쿼터의 상쇄 대상에서 제외**한다.
- 스튜디오 Basic 고객이 포함 A4 를 액자에 → 인화 €0 + 액자 €35 = **€35**
- 쿼터 소진 후 → 인화 €15 + 액자 €35 = **€50**
포토카드가 이미 쿼터 예외로 처리돼 있어 같은 방식으로 붙이면 된다.

### 4-3. 함께

- **소액 주문 취급료 €4** (주문 €12 미만) — 한 장짜리 주문의 핸들링 적자 방어
- 셀렉 화면: "하네뮐러 코튼 파인아트지"까지만. **보존 연수 문구 금지**
- 액자는 **픽업 전용** (유리 우편 발송 = 파손 클레임)
- IKEA 액자는 단종이 잦다 → 모델명 대신 "무산성 마운트 포함 목재 프레임"으로 표기, 30×40/40×50 각 3~5개 재고

## 5. 결정 필요

1. 인화 단가 개정 승인 여부 (A3/A3+ 인하 · 포토카드 차등)
2. 액자 도입 여부와 초기 재고
3. 소액 취급료 €4 도입 여부
4. 시그니처 라인의 실제 용지(하네뮐러 계열인지 RC 계열인지) — 재료비 재확인용
