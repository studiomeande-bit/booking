## 날짜 차단

**설정**: `custom_holidays` 에 2026-10-21~11-25 전체가 등록돼 있음(어드민 설정에서 관리).

**Code.gs 수정 (@725)** — `isWeekendOrHolidayBlocked_`:
기존에는 `wed`/`biz` 를 함수 맨 위에서 통째로 면제해, 사장님이 지정한 휴무일에도
프리웨딩·행사 슬롯이 열려 있었다(프리웨딩 Plus/Premium 은 상담 없이 바로 예약 가능한 상품).

- **`custom_holidays` 는 전 상품 차단** — 부재중이면 웨딩·기업도 촬영 불가
- 주말(일·월)·공휴일 정기휴무의 `wed`/`biz` 예외는 **그대로 유지** — "본식은 주말에 한다"는 정책이지 부재 사유가 아니다
- 마지막 줄의 중복 `custom_holidays` 판정은 죽은 코드가 되어 `return false` 로 정리

## 남은 운영 액션

- 기존 공지 "예약시스템 테스트 중입니다"(`notice_ko/en/de`)는 어드민 → 설정에서 비우면 사라짐.
  ⚠️ 설정 저장(`saveSiteSettings`)은 **전체 덮어쓰기**라 에이전트로 부분 수정하면 영업시간·휴무일까지 날아간다 — 어드민 UI에서 직접 할 것
