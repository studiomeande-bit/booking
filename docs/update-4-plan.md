## 배경

Phase 1(단가표 비노출·하이브리드 선택지·dolp)로 2트랙 기반이 깔렸다. 4개 관점 검증(매출/운영리스크/CX/누락)과
사장님 추가 지시를 반영한 확정안:

**사장님 지시 (2026-07-16):** ① 예약 첫 메뉴에서 B2B와 B2C(돌잔치/웨딩본식) 분리,
② 프리웨딩 ↔ 웨딩파티·암트결혼식 명확 구분, ③ 설명 텍스트 이해하기 쉽게.

**검증에서 나온 핵심 조정:**
- B2B 상담 전환은 processForm(전 예약이 지나는 핫패스)을 포크하지 않고 **기존 상담 설문 인프라 재사용**
  (상담시트·관리자/고객 메일·상담예약 캘린더 전부 이미 있음) → 리스크 대폭 감소, 캘린더 미점유 자동 달성.
- 하이브리드는 카테고리별 카드 남발 대신 **상담 접수 안의 사진/영상/사진+영상 3택**으로 (이미 존재하는 위저드 선택 + 상담 설문에 반영).
- 견적 드래프트 자동화는 **에이전트 경로만** — 어드민 버튼을 만들면 내부 단가표가 GAS에 들어가 Phase 1의 비노출을 되돌리게 됨. 거부.
- 계약금 인보이스는 **명시적 실행형**(수락 후 "계약금 인보이스 만들어줘") — STMIN 번호가 생성 시 소모되므로 자동 드래프트 금지.
- Drehvertrag(계약서) 자동화 → Update 5 백로그 (별도 문서 파이프라인, 연 2~4회 사용).

### A1. 첫 메뉴 재구성 (booking.js)

기존 6타일: 여권/프로필/스튜디오/야외·홈스냅/프리웨딩/행사·이벤트
신규 **7타일**:

| 타일 | 내용 | 동작 |
|---|---|---|
| 여권/비자 · 프로필 · 스튜디오 · 야외/홈스냅 | 현행 유지 | 예약형 |
| **프리웨딩 (커플 화보)** | 결혼 **전** 커플 컨셉 촬영 — "본식 기록 아님" 명시 | 예약형 (현행) |
| **웨딩 · 가족 행사 (B2C)** | 암트 결혼식(본식 당일), 웨딩 피로연/파티, 돌잔치/가족 파티 | 예약형 — 실제 행사 날짜 슬롯 점유 (정당) |
| **기업 · 단체 촬영 (B2B)** | 기업 행사, 일반 행사·공연·전시, 기업 출장 촬영(프로필·공간·제품) | **상담형** — 슬롯 미점유, 상담 설문으로 연결 |

- 내부적으로 두 행사 타일 모두 `g='biz'` 유지(백엔드 시맨틱 불변 — 버퍼시간/회계분류/재촬영룰 무변경). 프론트에서 카테고리 서브셋으로 분리.
- B2B 타일 카드는 상품이 아니라 **유형 카드**(기업 행사/일반 행사/출장 촬영) → 상담 설문 페이지로 type 프리셀렉트 링크. 날짜/슬롯 단계 없음.
- B2C 행사 타일: 암트 본식(amtp 고정가) · 웨딩파티(amtpr/amtpp/amtvr/amtvp/amtv 상담견적) · 돌잔치(dolp 고정가) — 현행 예약 플로우 유지.
- 시간제 generic `biz` 카드는 메뉴에서 숨김(레거시 호환 코드는 유지 — 구캐시 페이로드 서버 수용).

### A2. 설명 텍스트 전면 개선 (ko/en/de)

- 프리웨딩: "결혼 전, 웨딩드레스·커플 컨셉 화보 촬영" ↔ 웨딩·가족 행사: "결혼식·행사 당일 현장 기록" — 첫 문장에서 구분.
- 전 그룹 sub/카드 요약을 고객 언어로 (전문용어·내부용어 제거).
- B2B 상담 접수 성공 화면·안내에 **응답 SLA 문구**: "1–2 영업일 내 맞춤 견적" (ko/en/de).

### A3. 상담 설문 연결 강화 (consultation)

- 상담 설문에 접수 후 "1–2 영업일 내 견적" 문구.

### A4. 백엔드 소품 (Code.gs)

- amt/dol(웨딩급) 셀렉 세션 생성 시 리터칭단가 기본 €20 (§5-4 잔여 — 현재 일괄 €10).

### 게이트 테스트가 잡아낸 별건 결함 (Update 4 범위 밖, 별도 처리)

1. **공개 접수 전화번호가 시트에서 손상된다** — `neutralizeFormula_` 는 `+`/`-`/`@` 로 시작해도 **괄호가 있어야만**(`/\(/`)
   `'` 를 붙인다. 전화번호에는 괄호가 없으므로 무방비 → 시트가 수식/숫자로 파싱한다.
   실측: 상담시트 `+49 176 60939400` → **`#ERROR!`**(완전 소실), 예약시트 `+49 176 609 394 00` → **`4917660939400`**(`+` 소실).
   **관리자 메일에는 정상 표기**되므로 시트만 깨진다. 영향 경로 6곳: `createConsultation_` · `processForm` · `createPortfolioLead_` ·
