## 1. 현재 구조 진단

### 1-1. 상품 구성 (biz 그룹, 라이브 10개)

| id | 상품 | 가격 | 방식 |
|---|---|---|---|
| `biz` | 행사/이벤트 상담 (사진/영상 택1) | 시간제 자동계산 | 유형·시간·편집 선택 → 예약 |
| `amtp` | 암트 결혼식 사진 | **€350 (토 €400)** | 유일한 고정가 즉시예약 |
| `amtv` / `amtpr` / `amtvr` / `amtpp` / `amtvp` | 암트 영상·피로연·파티 | €0 상담 견적 | 슬롯 예약 → 견적 |
| `evp` / `evv` | 행사 사진/영상 | €0 상담 견적 | 슬롯 예약 → 견적 |

UI는 이미 4개 카테고리(암트 결혼식 / 돌잔치·가족파티 / 일반 행사 / 기업 행사)로 분리돼 있고,
가족/일반/기업은 전부 동일한 `evp`/`evv`/`biz` 3개 상품으로 수렴한다.

### 1-2. 발견된 문제

**(A) 내부 단가표가 공개 번들에 노출된다 — 핵심 문제.**
`booking.js`의 `BUSINESS_PRICE_META`(사진 2h €300 ~ 영상 풀편집 8h €2,600)가
고객 브라우저에 그대로 배포된다. UI 표시는 지웠지만(2026-07 정리), 소스 보기만 하면
전체 시간×편집 단가표가 보인다. `Code.gs:4453`에도 같은 표가 하드코딩돼 있어
`biz` 상품 예약 시 이 표로 총액을 계산해 장부에 기록한다.

**(B) 그 단가표가 실거래와 30~50% 괴리.**
실제 견적(아래 1-3)은 사진 8h ≈ €1,000 netto인데 표는 €880 **brutto**(= €740 netto).
영상 6h 실거래 €1,450 netto vs 표 €1,000 brutto(= €840 netto). 표가 노출되는 순간
실제 견적이 "비싸게 부른 것"처럼 보이는 역효과 구조다.

**(C) 하이브리드(사진+영상)가 상품에 없다.**
상품 문안은 전부 "사진/영상 택1"인데, 2026년 최대 계약(휘슬러 €2,700 netto)은
하이브리드였다. 실수요 최상위 패키지가 선택지에 없다.

**(D) 시간제 즉시예약 경로로 엉뚱한 고객이 들어온다.**
Anna Matsuura(9월 결혼식, Wiesbaden)가 `biz` 시간제로 "행사 사진 5시간 €750"을
예약 — 실제로는 웨딩 상담이 필요한 건이라 금액을 수동 조정했다. 남선현 건도
구 상품(맞춤 견적)으로 들어와 €350 수동 확정. 시간제 경로는 견적 상담을
우회하게 만들면서 정확한 금액도 못 만든다.

**(E) 상담 접수가 두 갈래로 이원화.**
- 예약 위저드 biz 경로 → 예약 시트 (유형·시간·편집 + 계산된 가격)
- 상담 설문 페이지(`/consultation`) → 상담 시트 (설문JSON, 가격 없음, 캘린더 상담예약 연동)

같은 성격의 문의가 두 시트에 다른 구조로 쌓여 후속 관리(견적 전환, D6 팔로업)가 갈라진다.

## 2. 제안 구조

### 2-1. 두 개의 트랙으로 분리

**트랙 1 — B2C 행사 (예약형, brutto 고정가):** 암트 결혼식 · 돌잔치/가족 파티
스코프가 예측 가능하므로 고정가 즉시예약을 유지·확대한다. (amtp 모델이 이미 검증됨)

**트랙 2 — B2B/맞춤 행사 (상담형, 가격 완전 비노출):** 일반 행사 · 기업 행사 · 암트 대형(파티) · 영상 전반
가격 계산을 클라이언트·서버 모두에서 제거하고, **구조화 상담 접수 → 내부 단가표로 견적**으로 통일한다.

### 2-2. 상품 개편안

| 카테고리 | 상품 | 방식 | 비고 |
|---|---|---|---|
| 암트 결혼식 | 사진 (90분) | **고정가 €350/토 €400** | 현행 유지 |
| | 사진+피로연 / 사진+파티 | 상담 | 현행 유지 |
| | 영상 / 영상+피로연·파티 | 상담 | 현행 유지 |
| | **사진+영상 하이브리드** | 상담 | **신설** |
| 돌잔치/가족 파티 | **파티 사진 2시간** | **고정가 신설 검토 (€350 안)** | 결정 필요 ① |
| | 사진 / 영상 / 하이브리드 | 상담 | 하이브리드 신설 |
| 일반 행사 | 사진 / 영상 / 하이브리드 | 상담 | 하이브리드 신설 |
| 기업 행사 | 사진 / 영상 / 하이브리드 | 상담 | 하이브리드 신설 |
| 기업 (신설) | **기업 출장 촬영 (포괄 B2B)** | 상담 | ② 확정 (2026-07-15): 포괄 상품명으로 — 임직원 프로필·팀 단체·공간/건축·제품/서비스 현장·인터뷰 영상을 한 상품으로 수용. 실적: LG·KOTRA·총영사관·AN-250004 |
| (제거) | `biz` 시간제 자동계산 경로 | **폐지 → 구조화 상담으로 대체** | 결정 필요 ③ |

- "택1" 문구 → "사진 / 영상 / 사진+영상" 3택 카드로 교체.
- `BUSINESS_PRICE_META`(프론트)와 `Code.gs` priceMap 삭제 — 노출 문제 (A)(B) 해소.

### 2-3. 구조화 상담 페이로드 (가격 없는 견적 재료)

biz 트랙 2 상품 선택 시, 날짜·슬롯 선택 대신(또는 이후) 아래 필드를 받는다.
**어디에도 금액을 계산·표시·저장하지 않는다.** 대신 견적에 필요한 재료를 전부 구조화한다.

```json
{
  "useCase": "civil | family | private | corporate",
  "mediaType": "photo | video | hybrid",
  "eventDate": "2026-10-09", "dateFlexible": false,
  "venue": { "name": "", "city": "", "type": "indoor|outdoor|mixed" },
  "hours": 6, "multiDay": false,
  "headcount": "~50",
  "deliverables": ["editedPhotos","allOriginals","highlightVideo","sameDaySocial","prints"],
  "videoEdit": "none | clean | highlight | full",
  "usageScope": "private | webSns | paidAds",
  "rush": false, "budgetBand": "700-1500",
  "company": { "name": "", "vatId": "", "billing": "" },
  "note": ""
}
```

- 저장처는 **상담 시트로 단일화** (설문JSON 필드 재사용, `source: booking-biz`).
  예약 시트에는 더 이상 가격 없는 biz 건을 쌓지 않는다 → 이원화 문제 (E) 해소.
- 기존 상담 설문 페이지는 유지하되 위 스키마와 필드명을 맞춘다 (coverage/deliverables 통합).
- 캘린더는 예약 확정 전에는 점유하지 않는다. 필요 시 어드민이 견적 보류+가예약(이미 구축됨)으로 홀드.

### 2-4. 접수 → 견적 자동화 (이미 있는 인프라 재사용)

1. 구조화 상담 접수 → 어드민 알림 메일에 요약 표
2. ERP 에이전트: 접수 페이로드 + 내부 단가표 → **견적 드래프트 자동 생성** (`quote-create`, 발송은 수동)
3. 이후는 기존 파이프라인 그대로: 보류/가예약 → D6 팔로업 → 수락 시 예약 전환

견적 라인아이템 프리셋(사진 풀데이 / 영상 6h / 하이라이트 편집 / 출장 / 이용권리 €0 라인 등)을
스킬 문서에 추가하면 견적 작성이 표준화된다.

## 3. 구현 단계 (결정 후)

**Phase 1 — 노출 제거 (즉시, 위험 낮음)**
- `BUSINESS_PRICE_META` 프론트 삭제, `Code.gs` priceMap 제거
- `biz` 상품 시간제 UI(유형/시간/편집) → 구조화 상담 필드로 교체, 총액 계산 중단
- 기존 진행 중 biz 예약(Anna 등)은 영향 없음 (이미 장부에 확정 금액)

**Phase 2 — 상품 재편**
- 하이브리드 상품 3종 신설 (amt·행사·기업), "택1" 문안 → 3택 카드
- (결정 시) 가족파티 고정가, 현장 프로필 상품 추가
- 상담 페이로드 스키마 통일 (booking biz 경로 + consultation 페이지)

**Phase 3 — 견적 자동화**
- 내부 단가표를 설정 시트에 저장 (비공개)
- 상담 접수 → 견적 드래프트 생성 에이전트 액션 + 프리셋 문서화
