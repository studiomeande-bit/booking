# ERP UI/UX 개편 1차: 디자인 토큰 + 사이드바 네비게이션

작성일: 2026-07-12 Europe/Berlin
대상: `appscript/AdminV2.html` (백엔드 무변경)
결정: 범위 = 리프레시 + 네비게이션 개편 / 톤 = 현재 슬레이트 유지·정돈

## 1. 디자인 토큰 (:root)

색·반경·그림자·포커스링을 CSS 변수로 도입:
`--brand(#2D2A26) --bg --bg-soft --surface --line --ink 계열 --ok --danger --warn --radius --shadow-sm/md --focus-ring`

핵심 프리미티브가 토큰을 사용하도록 전환: body, top-bar, 버튼(btn-*), 입력(input/select/textarea), 테이블(th/td), 모달.
장기적으로 나머지 하드코딩 hex도 점진 전환 가능(기능 영향 없음).

## 2. 접근성/사용성 정돈

- 입력 포커스: 브랜드 보더 + 포커스 링(box-shadow)
- 버튼: `:focus-visible` 아웃라인, `:disabled` 상태 추가
- 테이블: `th` sticky(스크롤 시 헤더 고정) + `.table-wrap` max-height로 긴 장부 내부 스크롤
- 커스텀 스크롤바(슬레이트 톤), 모달 그림자/백드롭 정돈

## 3. 네비게이션: 상단 16탭 → 그룹형 사이드바

| 그룹 | 항목 |
|---|---|
| 운영 | 대시보드 · 예약 장부 · 사진셀렉 · 추가 인화 · 수기 등록 |
| 고객 | 문의 리드 · 상담 · 마케팅 |
| 재무 | 회계 장부 · 현금 장부 · 인보이스 · 견적서 · 굿샤인 |
| 시스템 | 상품 관리 · 운영 로그 · 설정 |

- 데스크톱(≥1024px): 좌측 고정 사이드바(sticky, 216px), 활성 항목 브랜드 배경
- 모바일(<1024px): 헤더 아래 가로 스크롤 내비(그룹 라벨 숨김, 그룹 간 구분선, 44px 터치 타겟)
- 인쇄 시 사이드바 숨김

## 4. switchTab 리팩터

기존: `.tab` 인덱스를 하드코딩 배열과 대조(탭 추가 시마다 배열 수정 필요, 순서 어긋나면 오동작)
변경: `data-tab` 속성 매칭 — `t.dataset.tab===id`. 시그니처/로더 호출 완전 동일, onclick 49곳 무변경 호환.

## 5. 검증

- 인라인 JS 전체 구문 검사 통과
- 로컬 렌더 스모크 테스트: 사이드바 4그룹/16항목 렌더, switchTab 전환 정상(activeNav/activePanel 확인), 모바일 375px 가로 내비 + 예약 장부 화면 정상
- 실데이터 연동(google.script.run)은 배포 후 실화면에서 확인 필요
