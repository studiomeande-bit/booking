## 0-2. 견적형 상품 1종 개설 — **이게 Phase 0 의 핵심**

| id | 라벨 | 가격 | 동작 |
|---|---|---|---|
| `wallart_custom` | 대형·특별 규격 (견적) | **0** | 선택 시 금액을 올리지 않고 **요청만 접수** |

- 셀렉 화면에서 고객이 고르면 **"희망 사이즈·액자 여부"를 자유 입력**받아 세션 메모에 남긴다.
- 스튜디오가 랩 견적을 받아 회신 → 합의되면 `booking-set-amount` 계열로 **수기 청구**.
- **청구 공식:** `판매가 = 랩 매입가(액자·글레이징·배송 포함) + 작업비`
  **작업비 = max(35 €, 매입가 × 0.30)**

**€35 하한 근거** — 실소요 30분/건(파일 준비·소프트프루핑 15 + 발주 5 + 고객 응대·배송 문의 10).
€35 = 70 €/h 로 여권(65)보다 낫다. €15 면 30 €/h — 야외·MRT(35 €/h, 이미 "하한선" 판정)보다 낮은 상품을 새로 만드는 꼴이다.
대형 액자는 배송 파손이 실재하고, 랩이 재제작해도 **고객 응대는 스튜디오 몫**이다. 그 리스크 값이 작업비에 들어 있다.

**금액 0 인 상품이 청구 파이프라인을 깨지 않는지 반드시 확인할 것** — 쿼터·크레딧 계산, 결제요청 메일, 미수 판정(`Code.gs:343` explicitlyUnpaid 규칙)에 0원 항목이 섞였을 때의 동작.

# Phase 2 — 분기 make-vs-buy 리포트

## 2-1. 왜 두 시나리오인가

**액자 포함으로 팔면 프린터를 사도 인화분만 절감된다.** 액자·글레이징·배송은 계속 외주다.

| | € (60×80 추정) |
|---|---:|
| 랩 매입 (액자포함) | 90~120 |
| ├ 인화분 | 25~35 |
| └ 액자·글레이징·배송 | 65~85 |
| 자체 출력 재료비 (0.48 m² × 28 €/m²) | −13 |
| **시나리오 A 건당 절감** | **≈ 12~22** |

€3,000 ÷ €17 ≈ **176장**. 연 13장이면 13년 — **A 만으로는 절대 안 산다.**

**시나리오 B** = 인화 자체 + **액자도 자체 조달·조립**. 액자 프리미엄 €65~85 를 시판 액자(€25~40)로 대체하면 건당 절감이 €50~70 으로 뛴다. 대신 **조립 20분/건 + 유리 파손 + 재고**가 붙는다.

→ **리포트는 A·B 를 나란히 계산하고, B 는 조립 노동을 반드시 차감한다.**

## 2-2. 계산식

```
상수
  C_kit   = 3,000 €   장비 일습 net (SC-P7500 2,263 + 롤·잉크·프로파일링)
  M_paper = 28 €/m²   파인아트지 23 + 잉크 5
  L_rate  = 20 €/h    사장님 인건비
  T_asm   = 20 min    시나리오 B 액자 조립 시간

직전 12개월 실적에서
  N       = 외주 건수
  P_print = Σ 랩매입_인화분
  P_frame = Σ (랩매입_총액 − 랩매입_인화분)
  A_m2    = Σ 규격 면적

시나리오 A (인화만 자체)
  S_A = P_print − A_m2 × M_paper

시나리오 B (인화 + 액자 자체)
  S_B = (P_print + P_frame) − A_m2 × M_paper − F_market − N × (T_asm/60) × L_rate
        F_market = 시판 액자 실단가 합 (규격별 실조사값. 추정 금지)

회수기간 = C_kit / max(S_A, S_B)
```

## 2-3. 판정 기준

| 회수기간 | 판정 |
|---|---|
| ≤ 2년 | **구매 권고** |
| 2~4년 | 관망 — 다음 분기 재계산 |
| > 4년 | 자체 출력 안 함 |

**전제 조건 (미충족 시 회수기간과 무관하게 구매 보류):**
- 유동자산이 **가계 3개월분 이상** (2026-09 기준 1.4개월분 — 현재 미충족)
- 시나리오 B 로 갈 거면 **시판 액자 조달처가 실제로 확보**돼 있을 것. 없으면 사도 완제품을 못 만든다.
- 자체 출력 전환 시 **색이 랩 결과와 어긋나지 않는지** 샘플 확인 (기존 납품 고객과의 일관성)

## 2-4. 어디에 붙이나 — 새 인프라 만들지 말 것

- **`scripts/erp-agent.mjs` 에 액션 1개** 추가: `print-outsourcing-report`.
  인자 없이 호출하면 직전 12개월 집계 + 위 계산 + 판정을 출력.

## 회계

대형은 **매입원가가 있는 상품**이다. 자체 출력 인화와 공헌이익률이 다르다.

- 원장에서 **별도 계정 분리 필수.** 섞으면 KPI 1(영업일당 gross 149 €)이 오염된다 — 공헌이익률 87% 전제로 계산된 지표다.
- `Wareneinsatz`(랩 매입)를 대응 기록.
- **"수수료만 받는다"고 해도 장부는 재판매(Eigenhändler)다.** §3 Abs.11 UStG 상 중개(Agenturgeschäft)가 되려면 랩이 **고객 이름으로** 인보이스를 내야 하는데, Prodigi·WhiteWall 드롭십은 **스튜디오에게** 청구한다. 매출은 전액 인식.
- NL 업체 매입은 **역내취득 리버스차지 → UStVA Kz 89/61.** USt-IdNr. 제출. MRT §13b 처리와 같은 구조.
- 처리 기준은 `2026년 kontoauszug/CLAUDE.md` → `00_README_인덱스.md` 를 따른다.
