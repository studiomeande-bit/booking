## 1. 지금 상태

- **계약이 성립하는 시점**: 고객이 booking.studio-mean.com 에서 제출 → `대기중` + 접수 메일("Buchungsanfrage…") →
  사장님 확정 → **확정 메일 = 승낙 = 계약 성립**(`확정일시` 열) → 계약금은 확정 후 10일 안에 계좌이체.
  웹·메일로만 성립하므로 원격판매계약(§ 312c BGB)이고, 웹 화면으로 맺으니 **§ 356a 철회 버튼 대상**이다.
- **계약금 규칙**(`calculateQuote_`): 총액 €100 초과 + pass·biz·promo 아님 → €50 / wed → 20 % / 나머지 0.
- **철회 안내가 예약 흐름 어디에도 없다.** 유일한 문구는 Fotografenvertrag § 13(계약서 PDF). 그마저 현행 공식 서식과 다르다:
  ① 2026-06-19 부터 필수인 온라인 철회 기능 문장 없음(Art. 246a § 1 Abs. 2 Nr. 1 EGBGB)
  ② **Wertersatz 문장 없음**(Anlage 1 Gestaltungshinweis 6) — 이게 없으면 촬영 후 철회에도 대가를 못 받는다(§ 357a Abs. 2 Nr. 3)
  ③ 조문 번호 `§ 356 Abs. 4` → 현행 `Abs. 5` ④ "oder E-Mail" → 공식 "oder eine E-Mail".
- **현재 노출**: 안내 없이 확정된 개인 예약은 철회기간이 14일이 아니라 **12개월+14일**(§ 356 Abs. 4),
  촬영·납품 뒤 철회돼도 **전액 반환·대가 0**(§ 357a Abs. 2, EuGH C-97/22).

**여권 = 무구속 예약이 되는 이유**: 원격으로 시작했어도 사업장에서 최종 체결되는 계약은 원격계약이 아니다(EU 소비자권리지침 전문 20).
지금도 계약금·노쇼 비용이 없으니 실무는 이미 그렇다. 빠진 건 **화면·메일 문구**뿐 — 지금은 여권 고객도 "표준 촬영 계약에 동의"를 누른다.

**여가 예외에 기대지 않는 것을 권장**: 예외 조항은 좁게 해석되고, 사진 촬영이 "Freizeitbetätigung"이라는 확인된 판례가 없다.
틀리면 위 "현재 노출"이 그대로 남는다(12개월+14일, 대가 0, 경쟁사 Abmahnung). 반대로 철회권을 주는 쪽은 법이 명시적으로 허용하고
(§ 312g Abs. 2 첫머리 "soweit die Parteien nichts anderes vereinbart haben"), 비용은 **확정 후 14일 안 무료 취소**(계약금 전액 반환)뿐이다.
철회기간 중 촬영 건은 아래 (c) 체크박스로 **이미 한 만큼 대가**를 받는다.

## 3. 사장님 결정 사항

1. **여권은 "무구속 방문 예약"으로 명시** (권장) — 대안: 여권도 철회권 안내(여권은 대부분 급한 예약이라 매번 (c) 체크박스가 뜬다).
2. **여가 예외 미적용 — 개인 예약 전부 철회권 안내** (권장) — 대안: 웨딩·가족 행사만 "철회권 없음(§ 312g Abs. 2 Nr. 9)" 고지.
3. **철회 접수 시 자동 취소 안 함** (권장) — 기존 셀프서비스와 같게: 고객에게 수신확인 자동 발송 + 사장님 메일에 "예약 바로 취소" 버튼.
   환불은 기존 어드민 환불 이벤트로, **받은 금액 전액·14일 안·같은 결제수단**(취소 환불 규정 30/8/2일 적용 안 함).
4. **Fotografenvertrag § 13 도 같은 정본 문구로 교체** (권장) — 새 계약만 `FV-v2`, 이미 만든 `FV-v1` 은 서명본 재생성 포함 옛 문구 그대로.
