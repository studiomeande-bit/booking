# 예약 1:1 문의 스레드 + WhatsApp

작성일: 2026-07-13 Europe/Berlin
결정: 예약 고객의 추가 문의는 "기록이 남는 1:1 스레드"(자체 구현), 즉시 연락은 WhatsApp 버튼. 외부 채팅 위젯(A안)은 보류.

## 구조

- **저장**: 새 시트 `문의스레드` (일시/예약행/방향(고객·스튜디오)/작성자/메시지/읽음/알림상태)
- **인증**: 고객 포털과 동일한 HMAC ref (`row:N:token`) 재사용 — 별도 로그인 없음
- **공개 API**: `booking-messages`(조회) / `booking-message-send`(전송: requestId 중복방지 + 예약행당 20초 쿨다운 + 2000자 제한)
- **알림**: 고객 메시지 → 관리자 메일 / 관리자 답장 → 고객 메일(포털 링크 포함, 시그니처)
- **포털 UI**: status 페이지 "1:1 문의" 카드 — 말풍선 스레드 + 전송, 45초 폴링(탭 활성 시), ko/en/de
- **어드민**: 예약 상세 모달 "💬 고객 문의 스레드" 패널(읽음 처리 + 답장) + 운영보드 "고객 메시지" 카드(마지막 메시지가 고객이면 = 답장 필요)
- **WhatsApp**: 포털 인포 카드 + 포트폴리오 컨택트 3개 언어 페이지에 wa.me/4917660939400 버튼

## 검증
- Code.gs / AdminV2 인라인 JS / status.js 구문 검사 통과
