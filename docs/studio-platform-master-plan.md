# Studio mean 통합 플랫폼 기획서

작성일: 2026-05-05  
범위: 포트폴리오 사이트, 예약페이지, 셀렉페이지, 메일 자동화, 어드민, 회계/인보이스, 마케팅 운영

## 1. 목표

Studio mean의 운영 시스템은 단순 예약폼이 아니라 아래 흐름을 하나로 묶는 플랫폼이 되어야 합니다.

1. 포트폴리오에서 신뢰 형성
2. 문의 또는 예약으로 전환
3. 어드민에서 리드/예약/결제/촬영 준비 관리
4. 촬영 후 셀렉 링크 발송
5. 보정/인화/우편/픽업 관리
6. 후기, 포트폴리오 활용 동의, 재방문 예약으로 회수

최종 목표는 운영자가 매번 기억해서 처리하지 않아도, 시스템이 "다음에 해야 할 일"을 보여주고 고객에게 필요한 안내가 자동으로 나가는 구조입니다.

## 2. 현재 로직 검토 요약

### 2.1 예약페이지

현재 예약페이지는 Netlify 정적 프론트와 Apps Script API로 분리되어 있습니다.

- `init`, `quote`, `calendar-batch`, `slots`, `return-check`, `booking` API 사용
- 상품 선택, 옵션, 날짜/시간, 고객 정보 4단계 흐름
- 예약 제출 시 `processForm()`에서 처리
- 중복 예약 방지 Lock 적용
- 예약장부 저장
- Google Calendar 이벤트 생성
- 고객 접수 메일 발송
- 관리자 새 예약 메일 발송
- 추천 시간, 일반 가능 시간, 빠른 확정 여부 저장
- 재방문 할인, 웨딩 얼리 예약 할인, 마케팅 동의 할인 반영
- 행사/이벤트는 암트 결혼식, 돌잔치/가족 파티, 일반 행사, 기업 행사로 분리됨
- 대기자 등록, 워크인 정보 접수, 굿샤인 조회도 연결됨

### 2.2 메일 자동화

현재 이미 다음 메일 흐름이 존재합니다.

- 예약 접수 메일
- 관리자 새 예약 알림
- 예약 확정 메일
- 예약 취소 메일
- 고객 일정 변경 신청/관리자 승인/거절 메일
- 촬영 전 24시간 리마인드
- 예약금 7일 미입금 리마인드
- 예약금 10일 미입금 자동 취소
- 촬영 후 감사 메일
- 백일 촬영 후 돌촬영 추천 메일
- 셀렉 링크 발송 메일
- 셀렉 제출 고객 확인 메일
- 셀렉 미제출 리마인드
- 보정본 완료 메일
- 보정 후 후기/확인 메일
- 인보이스, 견적서, 굿샤인 PDF 발송 메일

문제는 메일 내용이 코드 곳곳에 흩어져 있고, 고객별 발송 이력과 실패 이력이 한눈에 보이지 않는다는 점입니다.

### 2.3 셀렉페이지

셀렉은 현재 운영에 필요한 주요 기능이 이미 들어가 있습니다.

- 세션 링크 기반 접근
- Drive 링크 표시
- 보정 사진 선택
- 마케팅 동의 시 보너스 컷
- 추가 보정/추가 인화 계산
- 포토카드 선택
- 픽업 날짜/시간 선택
- 우편 수령 주소 입력
- 기존 제출 내용 수정 가능
- 제출 시 예약장부 상태 `셀렉완료` 반영
- 추가금 발생 시 인화/보정 주문 생성
- 사업자 송장 요청 예약이면 추가금 인보이스 자동 생성
- 보정본 승인/재수정 요청 링크

개선 포인트는 고객이 Drive와 셀렉 페이지를 오가야 하는 점, 어드민에서 셀렉-보정-출력-우편발송이 하나의 작업 큐로 더 강하게 보여야 하는 점입니다.

### 2.4 어드민

현재 어드민은 기능이 매우 많습니다.

- 대시보드
- 예약 장부
- 회계 장부
- 추가 인화
- 수기 등록
- 상품 관리
- 사진셀렉
- 인보이스
- 굿샤인
- 견적서
- 설정
- Lexware 연동
- Twilio SMS
- 스튜디오 상주 시간 열기
- 추천 슬롯 진단

기능은 충분하지만, 운영자가 매일 봐야 하는 "우선순위 화면"이 아직 약합니다. 지금은 탭별 관리에는 강하지만, 오늘 무엇을 처리해야 하는지를 자동 정렬해 주는 구조가 필요합니다.

### 2.5 포트폴리오 사이트

포트폴리오는 현재 다국어 정적 사이트입니다.

- 독일어, 영어, 한국어 URL 분리
- SEO 기본 태그, hreflang, canonical, 구조화 데이터 반영
- Google Drive 기반 포트폴리오 JSON
- 카테고리 필터
- 문의 폼은 PHP `mail()` 기반으로 관리자 이메일 발송

가장 큰 개선점은 포트폴리오 문의가 어드민 CRM으로 들어오지 않는다는 점입니다. 지금은 메일만 오기 때문에 문의 추적, 답변 여부, 견적 전환, 예약 전환, 유입 경로 분석이 어렵습니다.

## 3. 핵심 문제 정의

1. 포트폴리오 문의와 예약 시스템이 분리되어 있어 리드 추적이 약함
2. 메일 자동화는 많지만 발송 로그/실패/재발송 관리가 약함
3. 어드민 기능은 많지만 "오늘 할 일" 중심의 운영 화면이 부족함
4. 마케팅 동의가 실제 포트폴리오 후보 선정/게시 흐름으로 이어지지 않음
5. 고객이 예약 후 자신의 예약 상태를 볼 수 있는 고객용 예약 포털이 없음
6. 행사/이벤트, 기업, 웨딩처럼 견적형 상품은 리드-견적-예약 전환 흐름이 더 필요함
7. Google Sheets 기반이 커지고 있어 데이터 구조와 자동화 로그를 더 엄격히 관리해야 함

## 4. 권장 전체 구조

### 4.1 고객 여정

1. 포트폴리오 방문
2. 카테고리별 랜딩에서 사례와 가격 방향 확인
3. 즉시 예약 가능한 상품은 예약페이지로 이동
4. 맞춤 견적 상품은 문의폼으로 접수
5. 문의는 어드민 `리드`로 저장
6. 리드에서 견적서 작성 또는 예약 전환
7. 예약 확정 후 촬영 전 체크리스트 자동 발송
8. 촬영 후 셀렉 링크 자동 또는 수동 발송
9. 보정본 전달, 출력/픽업/우편 관리
10. 후기 요청, 인스타 태그, 포트폴리오 활용 동의 회수
11. 백일-돌, 가족사진-연말, 프로필-1년 갱신 등 재방문 캠페인

### 4.2 운영자 여정

어드민 첫 화면을 `오늘의 운영 보드`로 재설계합니다.

- 오늘 촬영
- 내일 촬영
- 새 예약 대기
- 빠른 확정 가능 예약
- 수동 확인 필요 예약
- 예약금 미입금 경고
- 일정 변경 요청
- 촬영완료인데 셀렉 미발송
- 셀렉 발송 후 미제출
- 셀렉 제출 후 작업대기
- 재수정 요청
- 출력/우편 발송 대기
- 미발송 인보이스
- 미수금/부분 결제
- 새 문의 리드

각 항목은 바로 처리 버튼을 가져야 합니다.

## 5. 포트폴리오 사이트 기획

### 5.1 역할

포트폴리오는 예쁜 갤러리가 아니라 구매 결정을 만드는 첫 화면이어야 합니다.

- 독일 현지 고객: 신뢰, 지역성, 전문성, 명확한 안내
- 한국 고객: 언어 편의, 독일 현지 촬영 경험, 빠른 예약
- 기업 고객: 일정 관리, 결과물 목적, 인보이스, 사진/영상 동시 운영 역량

### 5.2 구조 개선

1. 홈
   - 대표 이미지와 짧은 브랜드 메시지
   - `Portrait`, `Family`, `Kids`, `Maternity`, `Standesamt`, `Outdoor Snap`, `Business/Event`, `Video` 진입
   - 바로 예약 가능한 상품과 상담이 필요한 상품을 명확히 분리

2. 서비스별 랜딩
   - `Passbild / Visa`
   - `Business Portrait`
   - `Family / Kids / Baby`
   - `Outdoor / Home Snap`
   - `Standesamt Hochzeit`
   - `Event / Corporate`
   - `Film / Video`

3. 각 랜딩 구성
   - 대표 작업 6-12장
   - 누구에게 맞는지
   - 진행 흐름
   - 시작가 또는 상담 견적 안내
   - 자주 묻는 질문
   - 예약/문의 CTA
   - 후기 또는 고객 문장

4. 문의폼 개선
   - PHP 메일 방식에서 Apps Script `lead-create` API로 전환
   - 어드민 `리드` 탭에 저장
   - 자동 답장 메일 발송
   - 리드 소스, 언어, 관심 상품, 희망일, 예산, 장소 저장

### 5.3 마케팅 기능

- Google/Naver 검색용 서비스별 SEO 페이지
- Google Business 리뷰 버튼 강화
- `Oberursel`, `Frankfurt`, `Rhein-Main`, `Korean photographer Germany` 키워드 구조화
- 캠페인 URL UTM 저장
- 방문자가 예약페이지로 넘어간 카테고리 추적
- 포트폴리오 사진별 카테고리/태그/노출 우선순위 관리
- 마케팅 동의 고객 사진을 `포트폴리오 후보`로 자동 표시

## 6. 예약페이지 기획

### 6.1 현재 유지할 장점

- 단계형 예약 흐름
- 추천 시간과 일반 시간 분리
- 상품별 옵션 계산
- 다국어
- Gmail 안내
- 사업자 인보이스 정보
- 웨딩/행사 분류
- 대기자 등록

### 6.2 추가할 편의기능

1. 임시 저장
   - 상품/날짜/이름/이메일 입력 중 이탈 시 localStorage 저장
   - 재방문 시 "작성 중인 예약 이어하기"

2. 예약 요약 고정 바
   - 모바일 하단에 상품, 날짜, 예상 금액, 다음 버튼 고정

3. 고객용 예약 포털
   - 예약 완료 후 토큰 링크 제공
   - 예약 상태 확인
   - 일정 변경 신청
   - 취소 요청
   - 인보이스 정보 추가
   - 안내 메일 다시 받기
   - 촬영 전 체크리스트 보기

4. 캘린더 추가
   - 예약 확정 메일에 `.ics` 또는 Google Calendar 추가 링크 제공

5. 상품 추천 질문
   - "무엇을 찍고 싶으세요?" 3-4문항으로 추천 상품 표시
   - 예: 여권/프로필/가족/야외/암트/기업

6. 노쇼/지각 방지
   - 촬영 전날 메일에 도착 시간, 주차, 준비물, 연락 버튼 포함
   - 촬영 당일 오전 SMS 또는 WhatsApp 링크 옵션

7. 견적형 상품 편의
   - 행사/기업/영상은 별도 질문 필드
   - 행사 목적, 인원, 장소, 필요한 결과물, 납품기한, 예산 범위
   - 제출 후 자동으로 어드민 리드/견적 후보 생성

8. 업셀
   - 가족/스냅: 추가 인화, 포토카드, 액자, 홈스냅 제안
   - 웨딩/암트: 피로연/파티 포함 옵션, 앨범/인화 제안
   - 프로필: LinkedIn/웹사이트용 추가 컷 제안
   - 여권: 가족 동반 촬영, 프로필 미니 세션 제안

## 7. 셀렉페이지 기획

### 7.1 고객 편의 개선

- Drive 폴더를 새 탭으로만 보내지 않고 셀렉 페이지 안에서 미리보기 강화
- 큰 이미지 보기, 키보드 좌우 이동, 별점, 비교 보기
- 자동 저장
- 마감일 카운트다운
- 사진 번호 직접 입력과 갤러리 클릭 선택을 동시에 지원
- "고민 중" 리스트와 "최종 선택" 리스트 분리
- 사진별 요청사항 예시 버튼
- 포토카드 앞/뒤 미리보기
- 추가금 발생 시 명확한 결제 안내
- 우편 수령 주소 재사용
- 픽업 예약을 Google Calendar 이벤트로 유지

### 7.2 운영 개선

- 셀렉 제출 후 자동으로 `작업대기` 큐 진입
- 재수정 요청은 최상단 경고
- 출력/우편 발송은 별도 체크리스트
- 우편 발송 시 송장번호/발송일 입력
- 보정본 발송 후 고객 승인 상태 추적
- 고객이 승인하면 출력/발송 또는 작업완료로 이어지는 버튼

## 8. 어드민 기획

### 8.1 핵심 화면: 오늘의 운영 보드

어드민 첫 화면을 업무 우선순위 중심으로 재구성합니다.

1. 오늘 촬영
2. 내일 촬영
3. 새 예약 대기
4. 리드 미응답
5. 견적 발송 후 미응답
6. 예약금 미입금
7. 촬영완료 후 셀렉 미발송
8. 셀렉 미제출
9. 작업대기
10. 재수정 요청
11. 출력/우편 발송 대기
12. 미수금

각 카드에는 바로 실행 버튼이 있어야 합니다.

- 확정 메일 발송
- 예약금 확인
- 셀렉 발송
- 보정본 발송
- 인보이스 발행
- 고객에게 메일 작성
- WhatsApp/전화 링크
- 작업완료 처리

### 8.2 고객 360 화면

고객 이름, 이메일, 전화번호 기준으로 통합 고객 상세 화면을 만듭니다.

- 예약 이력
- 문의 이력
- 견적 이력
- 셀렉 이력
- 인보이스/결제 이력
- 마케팅 동의 여부
- 포트폴리오 사용 가능 사진
- 메모
- 선호 언어
- 재방문 추천 상품

### 8.3 리드 관리

포트폴리오 문의, 인스타 수기 입력, 마이리얼트립, 전화 문의를 모두 리드로 저장합니다.

리드 상태:

- 신규
- 답변필요
- 견적준비
- 견적발송
- 예약전환
- 보류
- 종료

편의기능:

- 문의 내용에서 상품 자동 추천
- 견적서 바로 생성
- 예약 링크 생성
- 답변 템플릿 삽입
- 3일 미응답 리마인드

### 8.4 메일/메시지 로그

모든 자동/수동 메일은 `MessageLog`에 저장합니다.

필드:

- 발송일시
- 고객명
- 이메일
- 언어
- 예약행/셀렉행/리드행
- 메일 타입
- 제목
- 발송 결과
- 재발송 여부

어드민 기능:

- 최근 메일 보기
- 실패 메일 재시도
- 예약 상세에서 메일 타임라인 표시
- 템플릿 미리보기 후 발송

### 8.5 자동화 상태판

매일 실행되는 자동화가 많아졌으므로 헬스체크가 필요합니다.

- 24시간 리마인드 실행 여부
- 예약금 리마인드/자동취소 실행 여부
- 셀렉 리마인드 실행 여부
- 촬영 후 감사 메일 실행 여부
- 보정 후 후기 메일 실행 여부
- DB 백업 성공 여부
- 마지막 실행 시간
- 실패 로그

## 13. 가장 먼저 할 일

가장 효율적인 첫 작업은 새 기능을 크게 만드는 것이 아니라 아래 3개입니다.

1. `MessageLog`와 `AutomationLog` 추가
   - 이미 메일 자동화가 많아서, 발송/실패/중복 여부를 먼저 보이게 해야 합니다.

2. 포트폴리오 문의를 `Lead`로 저장
   - 지금 포트폴리오 문의는 메일로만 오기 때문에 매출 전환 추적이 끊깁니다.

3. 어드민 첫 화면에 `오늘 할 일` 카드 추가
   - 새 예약, 미입금, 셀렉 미발송, 작업대기, 재수정 요청, 미수금이 한 번에 보여야 합니다.

이 3개가 들어가면 지금 있는 예약/셀렉/메일 기능이 운영과 마케팅 양쪽에서 훨씬 잘 연결됩니다.
