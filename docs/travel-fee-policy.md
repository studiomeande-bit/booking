## 배경

- 현행 고객 노출 문구는 **"프랑크푸르트 반경 50km"** (스냅/프리웨딩) — 앵커가 스튜디오가 아니라 프랑크푸르트라
  비스바덴·마인츠·다름슈타트까지 무료가 되고, 오버우어젤에서의 실제 이동 부담과 어긋남.
- 실거래: KOTRA(프랑크푸르트 시내, ~20km) 출장 €80 netto / 휘슬러(1박 포함) €200 netto — B2B는 근거리도 청구해 왔음.
- 독일 시장 관행: **무료 반경(보통 ~30km) + km당 €0.30–1.00** (사진가 다수 €0.50/km 안팎, 최소 팔라우샬 병행).
- Anna Matsuura 사례(비스바덴 웨딩): 출장 부담이 견적에 반영 안 돼 수동 조정.

## 제안 정책

### B2C (예약 페이지 고정가 상품: 스냅 · 프리웨딩 · 웨딩/가족 행사)

**"스튜디오 기준 편도 30km까지 출장비 무료"** + 존별 정액:

| 존 | 스튜디오 기준 | 출장비 (brutto) | 해당 지역 예 |
|---|---|---|---|
| 1 | ~30km | **무료** | 프랑크푸르트 전역, 공항, 바트홈부르크, 쾨니히슈타인, 프리트베르크, 타우누스 |
| 2 | 30–60km | **+€30** | 비스바덴, 마인츠, 다름슈타트, 하나우, 기센 |
| 3 | 60–100km | **+€70** | 아샤펜부르크, 마르부르크, 하이델베르크(≈100km 경계) |
| 4 | 100km 초과 / 숙박 필요 | **상담 견적** | 코블렌츠, 풀다, 쾰른, 슈투트가르트 등 (B2B 단가표 준용) |

- 존2 €30 ≈ 초과분 왕복 km × €0.50 수준 — 시장 하단(경쟁력) + 실비 이상은 회수.
- 존3 €70 ≈ 실비 + 시간 일부 보전.
- 편도 거리 기준(구글맵 자동차 경로), 주차비 실비 별도(도심 행사장 등).

### B2B (내부 단가표 netto — 견적에만, 비노출) — **조명장비 변수 포함 자동 계산식**

```
출장비(netto) = 구간 기본요금 + (조명장비 동반 시 +€30)
brutto = netto × 1.19
```

| 구간 (스튜디오 기준 편도) | 기본 (조명 없음) | 조명장비 동반 |
|---|---|---|
| ~30km | €50 | €80 |
| 30–60km | €80 | €110 |
| 60–100km | €120 | €150 |
| 100km+ / 숙박 | €200 (1박 포함) | €230 + 추가 박당 €100–150 |

- **조명장비 가산 +€30**: 스트로보·스탠드·모디파이어 적재/하차 + 현장 세팅 시간 반영.
- 캘리브레이션: KOTRA(프랑크푸르트 ~20km, 현장 프로필 = 조명 동반) €80 실적과 정확히 일치. 휘슬러(1박, 영상 장비 위주) €200 일치.
- 조명 여부 기본값(견적 초안 시): 현장 인물/프로필·스튜디오형 세팅 = **동반**, 행사 스케치·다큐 = **미동반**. 애매하면 메모에 가정 명시.
- B2C 존 요금은 조명 변수 없이 유지 (B2C 행사 상품가에 이미 반영, 단순성 우선).

→ rate card(`references/event-rate-card.md`) §3에 공식 + 도시 거리표 반영 (완료).

### 현행 대비 변화 (고객 영향)

- **비스바덴·마인츠·다름슈타트 스냅/웨딩이 무료 → +€30** (현행 "프랑크푸르트 50km"에 포함돼 있었음).
  근거: 왕복 1.5–2시간 + €35~42 실비 — 지금까지 스튜디오가 전액 흡수.
- 프랑크푸르트 전역은 계속 무료 — 주 고객층(프랑크푸르트 교민) 영향 없음.
- MyRealTrip 스냅은 계약 상품이라 제외 (프랑크푸르트 시내 고정).

## 적용 지점 (확정 후 구현)

1. `GROUP_QUICK_FACTS` snap/wed/famevt place 문구: "프랑크푸르트 반경 50km" → "스튜디오 기준 30km 무료 · 이후 지역별 출장비"
2. `ob` 상품 설명 "프랑크푸르트 50km 이내" → 새 정책 문구 (상품시트 + 시드)
3. 부킹 위저드 위치 입력(snap/wed/famevt) 아래 존 안내문 + 성공 가이드 ("30km 초과 시 확정 메일에서 출장비 안내")
4. 견적서 기본 terms에 출장비 존 조항
5. rate card §3 갱신 + SKILL.md 요약줄
6. **자동 부과는 보류** — 거리 자동계산(Maps API)은 Update 5 후보. 당분간: 문구 안내 + 어드민 확정 시 수동 반영(30km 초과 위치면 확정 메일에 출장비 라인)
