## 1. 원칙 (브랜드 규정 적용)

- **광고가 아니라 준비 안내다.** 성공 화면·메일의 기존 "준비 가이드" 톤 그대로 — 조용하고 담백하게, 목록형.
  제목은 "함께 준비하시면 좋은 곳" (EN *Recommended partners* / DE *Empfohlene Partner*). 내부 명칭만 "협력업체".
- **사진이 주인공** — 로고·배너 금지. 업체명 + 한 줄 설명 + 상담 버튼 1개. 텍스트만.
- **결정 전에는 안 보인다.** 예약을 결정한 뒤(성공 화면)와 다시 읽는 문서(메일)에만. 히어로·상품 선택 그리드·동의/결제 단계에는 넣지 않는다 — 의사결정 방해 + 법적 동의 화면에 외부 링크 섞지 않기.
- **스튜디오 기본 제공과 충돌 금지.** 돌상/백일상 기본 셋팅은 이미 무료(프로필 프로페셔널 이상). 업체 C는 "더 풍성한 돌상·한복이 필요하면"으로 위치시킨다. 무료 안내 문구는 그대로 둔다.
- 예약·결제는 각 업체와 직접. 한 줄 고지: "Studio mean은 소개만 드리며 각 업체의 계약·결제에 관여하지 않습니다."

### 4-1. 데이터는 한 곳 (시트 `협력업체`)
세 군데에 하드코딩하지 않는다. `상품설정` 시트가 상품의 진실원장인 것과 같은 패턴으로 **시트 1장**을 두고 `ensureSheets_` 기본 헤더로 만든다.

|---|---|
| id | `makeup_dress` |
| 분류 | 메이크업·드레스 / 플로리스트 / 돌상·한복 |
| 업체명 | (사장님 제공) |
| 한줄설명 KO / EN / DE | "프리웨딩 메이크업·드레스 대여, 한국어 상담" |
| 상담언어 | KO / KO·DE / KO·EN — 독일 고객에게 중요 |
| 지역 | Frankfurt 등 |
| **바로상담 링크** | 카카오톡 채널 채팅 / 인스타 DM(`ig.me/m/…`) / WhatsApp(`wa.me/49…`) / 문의폼 — **대화로 바로 이어지는 링크 1개** |

| 노출위치 | `success,mail,dolmail,consult` |
| 순서 / 활성 | 1 / Y |
| 제휴조건 메모 | 내부용(할인·수수료 등) — 고객 노출 안 함 |

- 프론트는 이미 받는 `getInitDataCustomer()` 응답에 `partners` 배열로 실어 캐시(상품 카탈로그와 같은 경로). 메일은 서버에서 같은 시트를 읽는다.

### 4-4. 클릭 집계 — 누가 얼마나 눌렀나

현재 사이트 분석은 GA4(`G-YHP3VVZ6GN`)인데 **동의 배너를 누른 방문자만** 집계되고(독일 동의율은 보통 절반 안팎), **메일 속 링크는 GA가 아예 못 본다**(메일 클라이언트에서 JS가 안 돈다). 그래서 GA만으로는 "얼마나 클릭했나"에 답이 안 된다.

**설계: 우리 서버(GAS)에 집계 1줄 + 시트 1장.** 개인정보는 쓰지 않는다.

| 출처 | 방식 | 체감 |
|---|---|---|
| 성공 화면·상담 화면 (웹) | 클릭 시 `navigator.sendBeacon(…api=partner-click)` 로 집계 핑 → 실제 링크는 **바로 새 탭** | 지연 0. 동의 무관 전원 집계 |
| 확정 메일·돌 메일 | 링크를 **우리 도메인** `booking.studio-mean.com/go/<id>?s=mail` 로 적고, **Netlify Edge Function**(`/go/*`, 파일 1개)이 ① GAS `api=partner-click` 에 1행 핑(1.5초 타임아웃) → ② 대상 URL 로 302. 대상 URL 은 GAS `api=partners` 에서 읽고 10분 캐시 | 즉시(~0.3초), 주소 깔끔. **메일 클릭도 집계** + 업체 링크가 바뀌어도 이미 보낸 메일이 안 깨짐. (2026-08-19 사장님 제안 "내가 링크 만들어 리디렉션" 채택 — GAS 직접 경유안은 ~1초 이동중 화면이라 폐기. bit.ly 류 외부 단축은 DSGVO·스팸필터·신뢰 문제로 제외) |
| (보조) GA4 | `partner_click` 이벤트 — 동의한 방문자 한정, GA 콘솔용 | 있으면 좋고 없어도 됨 |

기록 시트 `협력업체클릭`: `일시 · 업체id · 출처(web/mail/consult/dolmail) · 언어 · 상품그룹`. **이름·이메일·예약행·IP 는 기록하지 않는다** — 그래서 동의 없이 집계해도 DSGVO 문제가 없다(식별 불가한 접근 수치). "어느 고객이 눌렀나"는 의도적으로 안 본다 — 알 필요가 없고, 알려면 동의 문제가 생긴다.

보는 곳: ① `weekly-kpi` 주간 리포트에 "협력업체 클릭 — 라온 7 · 가온 3 · cozyjoo 2 (웹 9 / 메일 3)" 한 줄, ② 에이전트 액션 `partner-click-stats --json '{"days":30}'` 로 기간별 조회. 어드민 카드는 Phase 3.

Phase 배치: 웹 집계 핑 + 시트 + `/go/` Edge Function 은 **Phase 1 에 포함**(나중에 끼우면 이미 나간 메일은 영영 못 센다). KPI 한 줄·stats 액션은 Phase 2.

### 4-3. 표기 의무 (법무 전제 — 독일)
- 단순 소개(대가 없음)는 외부 링크로 충분. 개인정보는 전달되지 않는다(클릭만).
- **수수료·할인 등 대가가 있으면** 상업적 협력임을 표기해야 한다(UWG 광고 표시). 그 경우 제목을 "협력 파트너(Kooperation)"로, 고지 문구에 한 줄 추가. §6-②에 따라 분기.
